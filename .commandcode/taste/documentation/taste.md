# Documentation & Setup Preferences

- When asked how to run a project, wants complete end-to-end startup instructions that assume no dependencies are pre-installed (Docker, Redis, PostgreSQL, etc.). Confidence: 0.8
- Prefers free or lightweight options for light usage of external services (e.g., a free embedding service for light use). Confidence: 0.7
- Wants config templates sanitized/desensitized with only the fields the user actually needs to fill left in. Confidence: 0.8
- Wants reusable operational documentation (start / stop / observe) committed into a repo-level `.ai` directory. Confidence: 0.7
